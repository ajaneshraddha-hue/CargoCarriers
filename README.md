- **Admin Management Portal**:
  - Secure management modal to view all submitted quotes
  - Status updates (Pending / In Review / Confirmed / Dispatched)
  - One-click CSV export of customer inquiries
- **Google Maps Integration**: Direct map pin for Kattedan, Hyderabad hub.
- **Responsive Design**: Optimized for smartphones, tablets, and desktop workstations.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, Modern CSS (Tailwind CSS CDN + custom physics animations), Vanilla JavaScript, Lucide Icons
- **Backend**: Node.js & Express.js REST API
- **Data Storage**: JSON-based persistent local datastore (`data/quotes.json`, `data/tracking.json`, `data/messages.json`)

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ajaneshraddha-hue/CargoCarriers.git
   cd CargoCarriers
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   node server.js
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
